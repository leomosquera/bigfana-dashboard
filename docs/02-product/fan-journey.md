# BigFana Fan Journey

## Purpose

This document defines the lifecycle of a fan inside BigFana.

The objective is to understand:

- how a fan enters the platform
- how engagement grows over time
- how loyalty is created
- how sponsors create value
- how EEP generates intelligence

This document is the foundation for:

- product design
- gamification
- loyalty programs
- sponsor activations
- segmentation
- future feature planning

---

# Fan Lifecycle

The fan journey follows a continuous cycle:

```txt
Join
    ↓
Discover
    ↓
Participate
    ↓
Earn
    ↓
Progress
    ↓
Redeem
    ↓
Advocate
    ↓
Repeat
```

The goal of BigFana is to continuously increase engagement and loyalty.

---

# Stage 1 — Join

The fan enters the platform.

Possible entry points:

```txt
Club Invitation

QR Code

Campaign

Social Media

Sponsor Promotion

Club Website

Ticket Purchase

Merchandise Purchase

Referral
```

---

# Registration

The fan creates an account.

Minimum information:

```txt
Name

Email

Country
```

Optional information:

```txt
Phone

Birth Date

Gender

City
```

---

# Organization Selection

The fan selects:

```txt
Primary Organization
```

Examples:

```txt
River Plate

Toluca

Real Madrid

Argentina National Team
```

Defined by:

```txt
ADR-001

ADR-002
```

---

# Stage 2 — Discover

The fan explores the ecosystem.

Examples:

```txt
News

Matches

Standings

Campaigns

Rewards

Benefits

Sponsors

Community Content
```

---

# Initial Personalization

The fan may optionally follow:

```txt
Organizations

Competitions

Sports
```

Examples:

```txt
Primary Organization:
River Plate

Followed Organization:
Real Madrid

Followed Competition:
Champions League

Followed Sport:
Basketball
```

---

# Stage 3 — Participate

The fan begins interacting with experiences.

Examples:

```txt
Trivia

Polls

Predictions

Surveys

Sponsor Activations

Challenges
```

Every interaction generates:

```txt
Fan Event
```

---

# Event Generation

Examples:

```txt
Campaign Participation

Content View

Reward Redemption

Match Interaction

Sponsor Click

Benefit Usage
```

These events are sent to:

```txt
EEP
```

for intelligence generation.

---

# Stage 4 — Earn

Participation generates value.

Examples:

```txt
Points

Badges

Achievements

Levels
```

---

# Point Sources

Examples:

```txt
Trivia Participation

Correct Prediction

Survey Completion

Daily Login

Sponsor Activation

Community Engagement
```

Organizations define the rules.

---

# Stage 5 — Progress

The fan advances through loyalty levels.

Examples:

```txt
Bronze

Silver

Gold

Platinum
```

Organizations define:

```txt
Level Structure

Required Points

Level Benefits
```

---

# Loyalty Ownership

Loyalty belongs to the organization.

Examples:

```txt
River Plate Gold Member

Toluca Platinum Member
```

Points and levels are organization-owned.

Defined by:

```txt
ADR-002
```

---

# Stage 6 — Redeem

The fan exchanges earned value.

Examples:

```txt
Tickets

Experiences

Merchandise

Sponsor Discounts

Exclusive Access
```

---

# Redemption Flow

```txt
Points
    ↓
Reward
    ↓
Redemption
```

Redemptions generate:

```txt
Fan Events
```

which are synchronized to EEP.

---

# Stage 7 — Advocate

The fan becomes an active promoter.

Examples:

```txt
Referrals

Community Participation

Content Sharing

Event Attendance

Sponsor Participation
```

Advocates are among the most valuable fan profiles.

---

# Stage 8 — Repeat

The journey never ends.

The fan continues participating in:

```txt
Campaigns

Competitions

Rewards

Benefits

Content
```

The objective is to continuously strengthen the relationship between:

```txt
Fan
    ↓
Organization
```

---

# Sponsor Journey

Sponsors participate throughout the fan lifecycle.

Examples:

```txt
Sponsored Campaigns

Sponsored Rewards

Sponsored Benefits

Sponsored Experiences
```

---

# Sponsor Value Flow

```txt
Sponsor
    ↓
Campaign
    ↓

    ↓

```
